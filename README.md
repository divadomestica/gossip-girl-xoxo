# XOXO · Gossip Girl - La Columna

La columna que todos leen y nadie admite. Un sitio web interactivo con panel de administración conectado a Supabase.

## Características

- 📝 Columnas dinámicas desde base de datos
- 🎨 Panel de administración para cambiar colores
- ✍️ Editor de artículos (crear, editar, eliminar)
- 📰 Ticker de noticias rotativas
- 💬 Rumores en barra lateral

## Tecnologías

- HTML5 / CSS3
- JavaScript
- Supabase (Base de datos y autenticación)

## Cómo usar

1. Abre el archivo `index.html` en tu navegador
2. Haz clic en el botón **👑 ADMIN** (abajo a la derecha)
3. Inicia sesión con tu usuario de Supabase
4. Comienza a gestionar tu columna
